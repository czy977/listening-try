# listening-try

给家里小孩简单弄的听力精听拼写网站。目前架构为追求快速简单，资料需要我先分析后上传才能够出现。

## 怎么使用

1. 打开网页:https://czy977.github.io/listening-try/ ，在课程列表中选择要练习的听力资料。
2. 选择电脑中对应的 BBC MP3；需要到官网下载对应音频到本地，使用时上传。音频只在本地读取，不会真的上传到网站。
3. 点击“播放本句”，输入听到的任意单词。
4. 拼写正确的单词会显示在原句位置，未完成的位置继续留空。
5. 完成整句或点击“查看完整答案”后，可以查看原句、重点词汇和解释。

每个句子默认播放三遍，每遍间隔两秒。进入下一句后会自动开始播放。

## 音频时间说明

句子时间由语音识别结果与 transcript 对齐生成。受识别误差和浏览器音频定位精度影响，个别句子的开头或结尾可能有少量偏差。如果音频与句子没有完全对齐，可以使用页面右上角的“校准模式”微调开始和结束时间。

## 文件说明

- `index.html`：网页结构
- `style.css`：页面样式
- `app.js`：播放、循环、拼写检查、复制和校准逻辑
- `lessons/catalog.js`：课程目录
- `lessons/260813.js`：第一期句子、词汇、释义和 ASR 时间戳
- `lessons/260813-alignment-report.json`：第一期的音频文本对齐检查报告
